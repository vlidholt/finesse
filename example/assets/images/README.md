# Docs example images

Photos, portraits and company logos that the docs examples show (avatars,
carousels, glass over a photograph, a timeline). They come from the designs
of [Demo](https://github.com/vlidholt/una_demo), the app the default
theme was measured from, which keeps the full set.

The directory is flat on purpose: Flutter asset directories are not
recursive, and `pubspec.yaml` declares this one directory.
